# ⚡ Unique In-Repo Web Project

यह रिपॉजिटरी पूरी तरह क्लाउड/ब्राउज़र पर चलने के लिए तैयार की गई है। इसके लिए लोकल मशीन पर Node.js या VS Code सेटअप की आवश्यकता नहीं है।

## 🛠 कैसे एडिट करें (In-Browser)

1. रिपॉजिटरी के मेन पेज पर जाएं।
2. कीबोर्ड पर **`.` (Period / Dot)** दबाएँ।
3. ब्राउज़र में VS Code खुल जाएगा—सीधे `index.html` में बदलाव करें और साइडबार से **Commit** कर दें।

## 🌐 वेबसाइट लाइव कैसे करें (GitHub Pages)

1. रिपॉजिटरी की **Settings** में जाएँ।
2. बाएँ मेन्यू से **Pages** चुनें।
3. **Branch** में `main` (या `master`) सेलेक्ट करके **Save** पर क्लिक करें।
4. 1 मिनट में आपकी साइट का लाइव लिंक स्क्रीन पर दिख जाएगा।
